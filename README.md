# Arco Design Pro Vite

The full Vite distribution generated from the `arco-design-pro-vite` template in
[qiyue2015/arco-design-pro-vue](https://github.com/qiyue2015/arco-design-pro-vue).

This repository contains the complete Admin9 Pro application. It includes all
dashboard, visualization, list, form, profile, result, exception, and user
modules from the source template. It is not processed by the simple-edition
pruning step.

## Requirements

- Node.js 14 or later
- pnpm

## Development

```bash
pnpm install
pnpm dev
```

## Verification

```bash
pnpm type:check
pnpm build
```

The production bundle is written to `dist/` and is intentionally not tracked.
